# ARIA — Avatar Interface

On-device AI companion with real-time 3D avatar, lip-sync, voice interaction, and multi-tier language models running entirely in the browser.

## Features
- Real 3D VRM avatars (Female / Male / Robot) with lip-sync and emotional expressions
- Voice input (push-to-talk) + voice replies
- Multiple model tiers powered by WebLLM (on-device)
- Local chat history and profiles
- Fully private — no data leaves the device

## Tech Stack
- Three.js + @pixiv/three-vrm
- WebLLM (MLC AI)
- Web Speech API
- Pure HTML / CSS / JavaScript

## How to Run
1. Open `index.html` in Chrome or Edge (WebGPU required)
2. First load downloads the selected language model (cached after)

## Go-To-Market
ARIA targets users who want a private, expressive AI companion without cloud dependency.  
Acquisition plan: Product Hunt, Twitter/X build-in-public, developer communities.
